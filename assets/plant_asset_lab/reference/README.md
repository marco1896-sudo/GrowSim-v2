# Reference Folder

Place non-production reference material here, such as approved style samples, plant morphology notes, symptom references, and generation comparisons. Do not place live app assets here.

Reference files should be named with source and purpose, for example:

- `reference_leaf_magnesium_pattern_notes.md`
- `reference_mid_flower_shape_v001.png`

Only use references that support biologically plausible, game-readable assets.
