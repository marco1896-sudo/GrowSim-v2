# Master Image Prompt

## Master Style Prefix

```text
Cannabis plant app/game asset, no pot, no soil, no background, transparent PNG, full plant visible, front-facing centered composition, consistent virtual bottom anchor, clean premium mobile game asset style, realistic but slightly stylized, botanically plausible leaf structure, strong silhouette readability at phone size, clean soft studio lighting, transparent padding around all leaves and buds, no text, no UI, no watermark, no extra objects, no hands, no tools, no lamp, no grow tent.
```

## Negative Prompt / Avoid List

```text
Avoid: pot, soil, ground plane, grow tent, lamp, tools, hands, people, labels, UI, watermarks, background scenery, cropped leaves, cropped buds, impossible cannabis morphology, random flowers, cartoon exaggeration, noisy photorealistic clutter, text inside the image, duplicate plants, malformed leaves, severe symptoms that contradict requested severity.
```

## Full Plant Alignment Add-On

```text
Use a 2048 x 2048 transparent canvas. Align plant centerline to canvas center X. Align the bottom of the visible main stem/root-stub area to the same virtual Y anchor used by the whole asset library. Leave transparent padding; do not crop any leaves or buds.
```
