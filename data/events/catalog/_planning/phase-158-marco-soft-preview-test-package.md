## 4. Detailtest
- Bild laedt?
- Titel/Event-ID verstaendlich?
- Score/Reason verstaendlich?
- Diagnose/Learning Preview hilfreich?
- Safety Labels sichtbar?
- No Resolve sichtbar?
- Kein Button wirkt wie echte Aktion?

## 5. Mobile-Test
- Viewports: 360, 390, 430, 768
- Lesbarkeit ausreichend?
- Bildausschnitt passend?
- Scrollverhalten sauber?
- Kein horizontaler Overflow?

## 6. Safety-Test
- Kein Resolve
- Kein Apply
- Kein Reward
- Keine Coins/XP
- Keine Missionaenderung

- Kein Save-Effekt
- Kein echter Event wird ausgeloest
