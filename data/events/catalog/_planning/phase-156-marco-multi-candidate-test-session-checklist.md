# Phase 156 - Marco Multi Candidate Test Session Checklist

## 1. Vorbereitung
- Lokale App starten.
- Dev/Test Guard aktivieren (`gs_event_v2_dev_preview=unlock`).
- Event V2 Dev Preview oeffnen.
- Event-Center Candidate Context oeffnen.

## 2. Multi-Candidate-Test
- Indoor Fixture waehlen.
- Candidate 1 Detail oeffnen.
- Bild + Text kurz pruefen.
- Zurueck zur Liste.
- Candidate 2 Detail oeffnen.
- Schliessen.
- Outdoor Fixture waehlen.
- Top Candidate oeffnen.
- Zurueck.
- Healthy Baseline waehlen.
- Top Candidate oeffnen.

## 3. Sichtpruefung
- Laden die Bilder sauber?
- Sind Titel/Event-ID verstaendlich?
- Sind Score/Reason nachvollziehbar?
- Ist Diagnose/Learning hilfreich?
- Sind Labels sichtbar?
  - Dev/Test
  - Candidate Only
  - No Write
  - No Resolve
  - No Gameplay Activation

## 4. Bedienung
- Ist Back klar?
- Ist Close klar?
- Kommt man ohne Verwirrung zur Liste zurueck?
- Fuehlt sich der Flow wie ein Feature an?

## 5. Inhaltliche Bewertung
- Indoor VPD plausibel trotz Watch?
- Outdoor Heat/Dry Wind klar erkennbar?
- Healthy Baseline ruhig genug?
- Wirken Bilder/Buddy passend?
- Sind Texte/Reasons zu technisch?

## 6. Safety
- Kein Resolve
- Kein Apply
- Kein Reward
- Keine Coins/XP
- Keine Missionsaenderung
- Keine Notification
- Kein Save-Effekt
- Kein echter Event wird ausgeloest

## 7. Entscheidung
- Bereit fuer Dev/Test Soft Preview im Event Center?
- Erst Copy/Label-Polish?
- Erst Scoring-Kalibrierung?
