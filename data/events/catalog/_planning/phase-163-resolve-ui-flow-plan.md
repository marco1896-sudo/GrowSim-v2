# Phase 163 - Resolve UI Flow Plan

## Event Detail (geplant)
- Bild
- Diagnose
- "Warum dieser Hinweis erscheint"
- Trefferstärke
- Testmodus/Vorschau-Hinweis

## Resolve Preview Section (geplant)
- Frage: "Was möchtest du tun?"
- 2-3 Optionen (anfängerfreundlich)
- Hinweis: `Noch keine echte Wirkung · nur Testvorschau`
- Klick zeigt: `Vorschau-Feedback` (gut/neutral/schlecht)
- Navigation: Zurück / Schließen

## Nicht erlaubt in dieser Stufe
- Kein echter Resolve-Button mit Persistenz
- Keine Belohnungen (Coins/XP)
- Keine Mission- oder Notification-Effekte
- Keine Runtime-/Save-Mutation

## UX-Prinzip
- Entscheidungsklarheit vor Systemtiefe
- Konsequenzlogik erklären, ohne zu mutieren
- Lernwert sichtbar, Risiko kontrolliert
