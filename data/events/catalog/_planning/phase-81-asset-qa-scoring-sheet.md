# Phase 81 Planning - Asset QA Scoring Sheet

## Score Model (0-2 each)
- Buddy consistency
- Event problem recognizable
- Botanical plausibility
- Mobile readability
- UI hero composition fit
- No wrong cause implication
- No overdramatization
- No text/speech bubble error
- No visual artifact problems
- Premium overall impression

## Total
- 18-20: accept
- 14-17: revise
- <14: reject

## Hard Reject Rules
- Buddy looks wrong
- wrong symptom for event
- text clutter or text corruption
- image not event-specific
- hero composition unusable for UI
