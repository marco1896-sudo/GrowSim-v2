# Phase 84 Background + Composite Workflow

## F) Background Prompt Rules (No Buddy)

### `shared_rootbound_warning`
- subject: pot + root zone pressure
- visible cue: constrained roots at edge/top and dense root mass
- stress level: mild, not catastrophic
- no Buddy, no text

### `outdoor_heatwave_dry_wind`
- subject: outdoor potted plant in heat + dry wind
- visible cue: moderate dryness stress, no apocalypse
- no rain/flood/disaster framing
- no Buddy, no text

### `shared_early_pest_signs_mild`
- subject: leaf underside with early mild pest traces
- visible cue: small speckles/traces, no heavy infestation
- no monster insects
- no Buddy, no text

## G) Composite Rules
- Buddy position per motif:
  - rootbound: lower-right pointing toward pot rim/root edge
  - heatwave: right-side warning pose, plant center-left
  - pest mild: right-side magnifier, leaf evidence center-left
- Buddy scale target: 22-32% of frame width (motif dependent)
- gaze direction: towards symptom anchor
- minimum distance to symptom anchor: 6-10% frame width
- safe area: avoid lower CTA zone and top chip zone
- crop resilience: verify 360/390/430px and 768px
- no speech bubbles in Phase 84/85

## H) Composite QA Strategy
Use three separated score blocks.

1. Background Score
- problem recognizable
- botanical plausibility
- mobile readability
- non-overdramatized
- no artifacts

2. Buddy Overlay Score
- buddy reference consistency
- pose fit
- clean cutout
- unobstructed buddy silhouette
- official buddy feel

3. Composite Score
- cohesive final image
- proper buddy scale/position
- light/shadow plausibility
- symptom remains clear
- UI hero usability

Hard reject if:
- buddy identity wrong
- event problem wrong
- unusable composite
- text clutter
- false causal cue

Accept gate:
- Buddy reference consistency must be 2/2
- plus no hard-reject trigger
