# Phase 87 Situational Overlay QA Scorecard

## Required Gates
1. `Buddy reference consistency` (0-2)
- 2 required for accept

2. `Situational relevance` (0-2)
- 2 = clear event-specific reaction
- 1 = roughly fitting but still generic
- 0 = generic sticker/no event relation

3. `Scene integration` (0-2)
- 2 = naturally placeable in scene
- 1 = usable but visibly overlay-like
- 0 = disruptive/wrong insertion

## Full Score Model (0-2 each)
1. Buddy reference consistency
2. Transparency/cutout cleanliness
3. Pose-event fit
4. Buddy fully visible
5. Leaf-crown integrity
6. Eye-language integrity
7. Color/style integrity
8. Mobile hero suitability
9. Edge artifact control
10. No text/speech bubble
11. Situational relevance
12. Scene integration

## Thresholds
- 22-24: `overlay_accept`
- 17-21: `overlay_revise`
- <17: `overlay_reject`

## Hard Reject (extended)
- Buddy identity below 2/2
- Situational relevance = 0
- generic sticker-like placement without scene relation
- unusable cutout/transparency
- cropped critical parts
- crown/face damage
- text/speech bubble
