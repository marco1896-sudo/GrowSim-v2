## Chain Visual Direction

### watering_rootzone_chain
- preferred treatment: `storyline-lite`
- visual path:
  - panic watering cue
  - dense or blocked medium
  - root-zone oxygen stress
  - calm recovery observation
- Buddy role:
  - supportive, de-escalating, not alarmist

### airflow_climate_chain
- preferred treatment: `systems storyline`
- visual path:
  - weak airflow
  - climate drift
  - hot dry pressure
  - exposure branch
- Buddy role:
  - guide who explains invisible system links

## Visual Consistency Rule
- Buddy should remain recognizable and warm across all event types
- use repeated pose families:
  - inspect
  - explain
  - caution
  - reassure
- avoid a new illustration style per event
- default fallback hierarchy:
  - event-specific Buddy image
  - event-specific plant/problem close-up
  - stable plant-only fallback
