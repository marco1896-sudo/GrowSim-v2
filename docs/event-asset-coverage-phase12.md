# Phase 12 Event Asset Coverage Note

Internal note for the focused registry/gap cleanup pass.

## Stronger coverage now

Explicit mappings were tightened for the most player-facing groups:

- common water warnings
- common pest outbreak states
- mold / humidity disease pressure
- root follow-up and root-pressure states
- a small set of reward / recovery states

## Still important gaps

The remaining high-priority gaps are now mostly distinct weather or positive-event visuals that do not yet have a convincing direct asset.

Use the gap list as the source of truth for what should still be created next.

## Mapping principle

Prefer:

- explicit event mapping first
- category fallback only when the visual is still truthful
- generic placeholder only when there is no honest existing match
