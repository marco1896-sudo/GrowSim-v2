# Event V2 UI-Lab

Isolierter UI-Prototyp für Event System V2 (Mini-Katalog), ohne Runtime-Anbindung.

## Zweck
- Mobile-first Visual/Flow-Prototyp für Event-Modal-Erlebnis.
- Test von Lesbarkeit, Coach-Ton, Decision-Flow, Learning-Card und Aftermath.

## Nicht enthalten
- Keine App-Integration
- Keine Event-Ausführung
- Keine Save-/State-Mutation in der echten Runtime

## Schnellstart (Preview)
1. Öffne `dev/event-v2-ui-lab.html` im Browser.
2. Wechsle Events über den Scenario-Switcher.
3. Wähle Optionen und prüfe Coach/Learning/Aftermath.
