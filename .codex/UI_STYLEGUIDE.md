# UI Styleguide – Grow Simulator

The UI should feel like a **premium mobile game**.

Design language:

* compact
* layered
* readable
* soft depth
* warm highlights
* high contrast where needed
* no cheap browser‑app feeling
* no oversized default HTML controls

Mobile‑first rules:

* safe‑area aware
* no overlapping bottom UI
* thumb‑friendly buttons
* compact cards
* avoid large scroll‑heavy modals
* test narrow iPhone layouts

Buddy usage:

* Buddy should feel alive and helpful
* Buddy should not be overused
* Buddy moments should support emotion, guidance, or reward

Animations:

* subtle
* responsive
* not distracting
* meaningful feedback for rewards, claims, boosts, and important state changes
