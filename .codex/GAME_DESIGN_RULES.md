# Game Design Rules

Grow Simulator is **not** a generic clicker game.

New mechanics should be:

* easy to understand
* meaningful for plant care
* connected to the core grow fantasy
* rewarding without feeling spammy
* balanced for long‑term retention

Avoid:

* meaningless grinding
* random rewards without explanation
* mechanics that punish casual players too hard
* UI overload
* too many currencies
* features that feel disconnected from growing plants

Preferred reward types:

* coins
* small boosts
* cosmetic unlocks
* temporary care advantages
* knowledge/progression feedback
* Buddy reactions
