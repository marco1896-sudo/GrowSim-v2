# Asset Pipeline – Grow Simulator

## Visual Target

* premium mobile game realism
* clean transparent PNGs
* no raw photo look
* no random backgrounds unless explicitly requested
* consistent perspective
* consistent scale
* consistent lighting
* no text inside generated images unless requested

## Buddy Assets

* Buddy must stay recognizable
* green mascot character
* friendly, expressive, premium look
* avoid inconsistent body shape, face shape, or cheap cartoon style

## Plant Assets

* transparent background
* no pot unless requested
* full plant visible
* centered
* uncropped
* consistent stem anchor
* stage progression must be believable

## Process for New Asset Tasks

1. define asset purpose
2. define dimensions
3. define style reference
4. define naming convention
5. generate or request assets
6. verify consistency
7. integrate into code only after approval
