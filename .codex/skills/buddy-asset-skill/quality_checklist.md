# Buddy Quality Checklist

## Score 0-2 Each

- Buddy reference consistency
- Situational action
- Scene integration
- Event symptom clarity
- Botanical plausibility
- Mobile hero readability
- Brand consistency
- No text artifacts
- No overdramatization
- Premium overall effect

## Thresholds

- 18-20: accept candidate
- 14-17: revise candidate
- under 14: reject candidate

## Hard Reject

Reject immediately if any condition is true:

- Buddy reference consistency is less than 2/2.
- Buddy looks like a different mascot or generic plant character.
- Buddy is only passively placed with no event-specific action.
- Buddy looks pasted on when the target is full-scene generation.
- Head shape, leaf-crown, eyes, body form, or color palette drift.
- Event symptom is wrong, hidden, or biologically implausible.
- Text artifacts, speech bubbles, logos, or UI text are present.
- The image is not usable as a mobile event hero.

## Review Method

Always compare the generated candidate side-by-side with the selected official references. Do not score from memory.
