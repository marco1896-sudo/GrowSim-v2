# Buddy Reference Usage

## Reference Roles

Use at least two official references for a full-scene Buddy event trial:

- identity reference: master front neutral or master front happy
- pose or perspective reference: emotion, pose, or side/profile image matching the action

## Selection Rules

- Prefer `master/front_neutral` for proportions and face.
- Use `side/profile` when the scene needs directional attention.
- Use `surprised_raised_hands` for warning, but keep coach tone calm.
- Use `confused_head_scratch` for inspection or "look closer" moods.
- Do not use angry, sad, or playful references unless the event tone really needs them.
