# Grow Simulator

Mobile-first PWA for grounded plant growth simulation with local saves and optional cloud-connected features.

## Visual Target

![GrowSim premium visual target](/docs/premium-reference.png)

## Run

Start the local static dev server from the project root:

```bash
npm run dev
```

Then open `http://0.0.0.0:5173`.

Optional:

```bash
PORT=5180 npm run dev
```
